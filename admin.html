Set up or replace the keys

Keys are made here in your browser and never sent anywhere. Copy each into the place listed, then push any change (or redeploy) so Cloudflare picks them up. Making new push keys turns alerts off for everyone who has them on; they'd need to switch them on again.

  1. Cloudflare → Workers & Pages → firetiger-fishing-log → Settings → Variables and Secrets: add secrets VAPID_PUBLIC, VAPID_PRIVATE and PUSH_CRON_KEY.
  2. GitHub → the repository → Settings → Secrets and variables → Actions: add a repository secret PUSH_CRON_KEY with the same timer key.
